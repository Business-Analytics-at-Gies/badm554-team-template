# Starter notebooks

Copy the starter for the current module into your own folder before you begin:

```
cp templates/M1-starter.ipynb members/<your-netid>/M1.ipynb
```

Each starter has the same three parts: **A** pre-AI attempt (commit and push it before starting B), **B** queries, **C** AI Attribution Log, then a short reflection. Submit the finished `.ipynb` on the Canvas assignment and push it to your folder.
