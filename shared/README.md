# shared/

Instructor-seeded starter files live here, and from Module 6 onward this is where team deliverables come together.

**Read-only until Module 6.** Before then, if a shared file needs changing, the designated integrator for that milestone makes the change — one person per milestone, agreed in advance.

**Where your own work goes (Modules 1 to 5):** inside `members/<your-netid>/`, and nowhere else — not in this folder, and not at the top level of the repository. If a file of yours landed here or at the root, move it into your folder in your next commit.
